# 福彩推荐系统 — 用户手册

> 本手册面向彩票店老板和日常使用者，不包含代码实现细节。
> 技术文档见 `docs/architecture.md` 和 `docs/design.md`。

---

## 1. 这是什么

一个给**彩票店老板**用的推荐工具。

**不是**预测中大奖的机器。彩票本质随机，没有任何算法能保证中一等奖。

**是**一个帮你：
- 给顾客提供"有理论依据"的号码推荐
- 用数据说话，建立专业形象
- 让顾客觉得"这家店靠谱"
- 避免顾客问你"今天买啥"时你只会说"随便"

```bash
python scripts/strategy_ranking.py --window 200 --backtest 50
```

输出各策略过去 50 期的表现：

```

保守型:  1.24个红球 (最接近随机baseline 1.09)
```

> ⚠️ 排行榜显示所有策略长期都是亏钱的。这是正常的——彩票本身就是负期望游戏。

### 3.3 生成综合日报

```bash
python -c "from src.analysis import generate_comprehensive_report; print(generate_comprehensive_report('ssq'))"
```

输出包含：
- 号码频率统计（哪些号热、哪些冷）
- 遗漏值分析（哪些号"该出"了）
- 策略 ROI 分析

适合每周看一次，了解整体走势。

### 3.4 用机器学习预测（高级）

```bash

python scripts/train.py --name ssq --method xgb

```

输出：

## 4. 四种策略说明

| 策略 | 思路 | 适合顾客 |
|------|------|----------|
| **保守型** | 选近期出现次数最多的热号 | 相信"热者恒大"的老顾客 |
| **激进型** | 选遗漏最大、最久没出的冷号 | 认为"该出了"的顾客 |
| **平衡型** | 兼顾和值、奇偶、区间均衡 | 追求"看起来合理"的顾客 |
| **玄学型** | 用幸运数字组合 | 有自己幸运数字的顾客 |

> 四种策略都给你，让顾客自己选。避免"你给我推荐一个然后没中"的尴尬。

## 6. 常见问题

### Q: 这个系统能保证中奖吗？
**不能。** 双色球头奖概率 1/17,721,008。任何算法、任何 AI 都无法改变这个概率。

### Q: 为什么所有策略 ROI 都是负的？
因为彩票本身就是负期望游戏。彩票中心要抽 50% 作为公益金，所以长期买必亏。

### Q: 那这个系统有什么用？
- 给顾客一个"有依据"的推荐，比随机选看起来专业
- 四种策略让顾客自己选，避免事后争执
- 数据可视化让顾客觉得你在认真分析
- **核心目的：提升顾客体验，不是预测中奖**

### Q: 需要每天更新数据吗？
不需要。历史数据已经够用（双色球 3277 期）。新数据可以每月更新一次：
```bash
python scripts/get_data.py --name ssq
```

### Q: 可以加自己的幸运数字吗？
可以。用玄学型策略，修改 `src/recommendation.py` 中的 `lucky_numbers` 列表。

### Q: 预测结果和推荐不一样？
正常。预测是 ML 模型输出，推荐是策略引擎输出。两者独立，不需要一致。

## 7. 输出给顾客的话术建议

**推荐时：**
> "这是我们系统基于 3000 多期历史数据跑出来的四种方案，您看看哪种合眼缘？"

**没中奖时：**
> "历史表现不代表未来结果，彩票本质随机，就当给生活添个小盼头。"

**顾客问"今天买啥"时：**
> "我这边有四种风格——追热号、追冷号、均衡型、幸运数字，您平时喜欢哪种？"
