# 福彩推荐系统

> 面向彩票店老板的号码推荐工具 — 用数据说话，给顾客"有理论依据"的推荐。

## 这是什么

一个帮你给顾客提供号码推荐的工具。

**不是预测中大奖的机器。** 彩票本质随机，任何算法都无法保证中一等奖。

**是**帮你：
- 给顾客提供四种不同风格的号码推荐
- 用历史数据建立专业形象
- 避免"今天买啥"的尴尬

---

## 支持的彩种

| 彩种 | 格式 | 状态 |
|------|------|------|
| 双色球 | 6红+1蓝 | 完整支持 |
| 福彩3D | 3位数字（含试机号） | 完整支持 |
| 七乐彩 | 7红+1特别号 | 完整支持 |
| 快乐8 | 选10 | 数据源不可用 |

---

## 四种推荐策略

| 策略 | 思路 | 适合顾客 |
|------|------|----------|
| **保守型** | 选近期出现次数最多的热号 | 相信"热者恒热"的老顾客 |
| **激进型** | 选遗漏最大、最久没出的冷号 | 认为"该出了"的顾客 |
| **平衡型** | 兼顾和值、奇偶、区间均衡 | 追求"看起来合理"的顾客 |
| **玄学型** | 用幸运数字组合 | 有自己幸运数字的顾客 |

## 安装和启动

### 第一次安装

**环境要求：** Python 3.13+，Windows / Linux / macOS 均可。

```bash
# 1. 安装依赖
pip install -r requirements.txt

# 2. 配置密码（必须！不设密码无法启动）
copy .env.example .env
# 用记事本打开 .env，在 LOTTERY_PASS= 后面填写你的登录密码
```

### 启动服务

**Windows 一键启动：**
```bash
start_server.bat
```

**手动启动：**
```bash
python -m uvicorn src.api:app --host 0.0.0.0 --port 8000
```

启动后浏览器访问 **http://localhost:8000** ，用你设置的密码登录。

> 首次启动会自动下载历史数据（双色球、福彩3D、七乐彩），可能需要几分钟。系统每日 01:03（北京时间）自动同步增量数据并智能训练模型。

## 日常使用

### 网页界面（推荐）

1. 浏览器打开 http://localhost:8000
2. 输入密码登录
3. 点击顶部标签切换彩种（双色球/福彩3D/七乐彩/快乐8）
4. 页面自动显示：推荐号码、历史走势、冷热号统计

### 命令行工具

```bash
# 生成今日推荐（最常用）
python scripts/generate_recommendation.py

# 查看策略排行榜
python scripts/strategy_ranking.py

# 更新数据
python scripts/get_data.py --code ssq
```

## 常见问题

### 启动报错"LOTTERY_PASS 环境变量未设置"

需要先配置密码。复制 `.env.example` 为 `.env`，然后填写 `LOTTERY_PASS=你的密码`。

### 端口被占用

修改启动端口：`start_server.bat 8080`，或手动指定：`python -m uvicorn src.api:app --port 8080`

### 快乐8没有数据

快乐8数据源（500.com 趋势图）当前不可用，前端已隐藏该彩种标签页，后端逻辑保留待恢复。

### LSTM/Stacking 显示"待升级"

云平台（FastAPI Cloud 等）运行 Python 3.13+，TensorFlow 尚未支持该版本，因此 LSTM 和 Stacking 方法不可用。本地部署（Python 3.11/3.12）安装 TensorFlow 后即可使用全部四种方法。

### 每日自动同步

系统每日 01:03（北京时间）自动执行：增量数据同步 → 智能训练（仅在有新数据时训练）。也可在网页点击"更新数据"手动触发。

### 忘记密码

打开 `.env` 文件，查看或修改 `LOTTERY_PASS` 的值。

## Docker 部署（适合有服务器的用户）

基于 Python 3.13-slim 镜像，端口 8080。

```bash
# 1. 配置密码（必须！不设密码容器无法启动）
copy .env.example .env
# 编辑 .env 填写实际密码

# 2. 构建并启动
docker-compose up -d --build

# 3. 访问
http://localhost:8080
```

> **注意：** `LOTTERY_PASS` 环境变量为必填项，缺失时服务拒绝启动。云平台部署请在平台控制台设置此环境变量。

---

## FastAPI Cloud 部署

支持一键部署到 [FastAPI Cloud](https://fastapicloud.dev)：

1. 将代码推送到 GitHub 仓库
2. 在 FastAPI Cloud 连接仓库，自动构建部署
3. 在平台控制台设置环境变量 `LOTTERY_PASS`（必填）

**注意事项：**
- 平台运行 Python 3.13+，TensorFlow 不可用，LSTM/Stacking 显示为"待升级"
- 端口由平台自动分配，无需配置
- 每日 01:03（北京时间）自动同步数据并智能训练
